# 반도체 섹터 강의요약본

원본 산업보고서(`sector1_반도체 총 정리.docx`)를 기반으로 만드는 강의용 요약본입니다.

## 강의 4단계 구조

각 강의는 다음 4단계로 구성됩니다.

1. **보고서 기반 강의** — 프로젝트 보고서 내용을 풀어서 설명
2. **외부 검증** — 같은 주제를 외부 자료로 다시 확인 (일치 / 다른 부분 / 보고서에 없는 추가 사실)
3. **차이 분석** — 보고서와 외부 자료가 다르면 왜 다른지, 어느 쪽이 더 정확한지
4. **역강의** — 본인 말로 핵심 5가지 정리 → 검증·보완

## 티커 표기 규칙

- **미국**: `(NVDA)`, `(MSFT)` 등 영문 코드
- **한국**: 6자리 숫자 코드 `(005930)` (KOSPI/KOSDAQ 구분 생략)
- **일본**: `(JP:8035)` (Tokyo Stock Exchange 4자리)
- **대만**: `(TW:2330)` (Taiwan Stock Exchange 4자리)
- **독일**: `(DE:SIE)`
- **비상장 / 상장폐지**: 명시 (예: `(비상장)`, `(상폐 2024.6)`)
