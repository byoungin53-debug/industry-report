## 강의 4단계 구조

각 강의는 다음 4단계로 구성됩니다.

1. **보고서 기반 강의** — 프로젝트 보고서 내용을 풀어서 설명
2. **외부 검증** — 같은 주제를 외부 자료로 다시 확인 (일치 / 다른 부분 / 보고서에 없는 추가 사실)
3. **차이 분석** — 보고서와 외부 자료가 다르면 왜 다른지, 어느 쪽이 더 정확한지
4. **역강의** — 본인 말로 핵심 5가지 정리 → 검증·보완
